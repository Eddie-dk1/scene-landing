# SCENE

Сайт: https://eddie-dk1.github.io/scene-landing/

Репозиторий: https://github.com/Eddie-dk1/scene-landing


Новый самостоятельный проект: концепт AI-студии коротких вертикальных видео.

## Текущий этап

Готов работающий локальный сайт: **http://127.0.0.1:5174/**. Пользователь выбрал объединение второго и третьего направлений: яркий синий фон, большая типографика, кинематографический кадр, бумажная заметка и стрелки.

Исходные три концепции сохранены для истории:

1. **Монтажный стол** — concepts/01-editing-table.png
2. **Живой коллаж** — concepts/02-living-collage.png
3. **Сцена одним кадром** — concepts/03-one-scene.png

Объединённый макет и референсы секций находятся в concepts/hybrid/. Разбор — docs/hybrid-direction.md. Точные промпты — docs/image-prompts.json и docs/hybrid-image-prompts.json.

## Запуск и проверка

Node.js 22.18+ или 24+. Локально проверено на Node.js 25.8.1.

```sh
npm ci
npm run dev
```

Открыть http://127.0.0.1:5174/. Сервер слушает только локальный интерфейс. После его остановки повторить npm run dev.

```sh
npm test
npm run build
npm run preview
```

Статическая сборка находится в dist/. В ней используются относительные пути для размещения в подпапке хостинга.

## Согласованная реализация

- Пять секций: первый экран, процесс, примеры, интерактивное превью, финальный призыв.
- Три сценария: приложение, путешествие, спорт.
- Каждый сценарий: три заранее подготовленные сцены по пять секунд.
- Стили: спокойный и динамичный.
- Запуск, пауза, продолжение, повтор и перемотка.
- Смена сценария или стиля возвращает начало и останавливает превью.
- Начальное состояние: приложение, динамичный стиль, воспроизведение остановлено.
- Vite + TypeScript + CSS, без сервера и платного AI API.
- Отдельный локальный адрес на порту 5174.
- Секции и управление должны помещаться на телефоне и в коротком окне ноутбука, включая высоту 600–625 px.
- Нативная прокрутка, уменьшенное движение, остановка фоновой анимации в скрытой вкладке.

Основной инструмент — Codex. Макеты созданы встроенной генерацией изображений.

Фотографии и бумажная фактура сгенерированы, сжаты в WebP и хранятся в public/assets/. Montserrat и Manrope с кириллицей хранятся локально; лицензии SIL OFL лежат в public/fonts/. Текст, заметки, стрелки, направляющие и интерфейс — отдельные HTML/CSS/SVG-элементы.

Результаты проверки — docs/qa.md, скриншоты — docs/screenshots/. Текст для работодателя и два ключевых промпта — docs/submission.md.

## Публикация

Публикация одобрена пользователем 3 ноября 2026 года. GitHub Actions запускает тесты, собирает сайт и публикует dist/ через GitHub Pages при обновлении ветки main. Конфигурация — .github/workflows/pages.yml. FORM хранится в отдельном репозитории.

Исходный референс: https://invix-solution.com/ — принципы типографики и последовательного раскрытия продукта. SCENE использует собственную тему, композицию, палитру и визуальные материалы.
