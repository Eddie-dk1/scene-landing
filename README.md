# SCENE

[Открыть сайт](https://eddie-dk1.github.io/scene-landing/)

## Идея

Лендинг концепта видеостудии: идея превращается в сценарий, кадры и короткую историю. Интерактивная студия позволяет выбрать подготовленный сценарий, характер переходов и посмотреть вертикальное превью. Визуальный стиль сочетает кобальтовый фон, крупную типографику, фотографии и бумажные заметки.

## Технологии

- Vite, TypeScript, HTML, CSS и SVG.
- Нативные браузерные анимации и requestAnimationFrame.
- Node.js Test Runner для тестирования проигрывателя.
- Sharp для оптимизации изображений в WebP.
- GitHub Actions и GitHub Pages для сборки и публикации.

## Возможности

- Три сценария: приложение, путешествие и спорт.
- Каждый сценарий состоит из трёх подготовленных сцен по пять секунд.
- Спокойный и динамичный стили меняют типографику и переходы.
- Воспроизведение, пауза, продолжение, повтор, перемотка и переход к отдельной сцене.
- Смена сценария или стиля останавливает воспроизведение и возвращает начало.
- Адаптивная вёрстка, управление клавиатурой, поддержка prefers-reduced-motion и пауза в скрытой вкладке.

Сайт статический. Сценарии и медиа хранятся локально; сервер и внешние API не требуются.

## Запуск

Требуется Node.js 22.18+ или 24+.

```sh
npm ci
npm run dev
```

Локальный адрес: http://127.0.0.1:5174/.

```sh
npm test
npm run build
npm run preview
```

Production-сборка создаётся в dist/. Относительные пути поддерживают размещение в подпапке хостинга.

## Структура

- src/main.ts — интерфейс и обработка действий.
- src/player.ts — проигрыватель по монотонным часам.
- src/stories.ts — данные сценариев и сцен.
- src/style.css и src/refinements.css — оформление, анимации и адаптивность.
- public/assets/ — изображения WebP.
- public/fonts/ — локальные шрифты Montserrat и Manrope, лицензии SIL OFL.
- tests/ — тесты проигрывателя и контента.
- docs/ — техническая документация и результаты проверки.

## Публикация

При push в main GitHub Actions устанавливает зависимости, запускает тесты, собирает сайт и публикует dist/ через GitHub Pages. Конфигурация — .github/workflows/pages.yml.
